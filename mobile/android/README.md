# تطبيق Android — BSCH Clinics

يعمل التطبيق بواجهة BSCH الأصلية. عند توفر الإنترنت يتصل مباشرة بمشروع Supabase `xqgjggvydcheqpjmrmgq` عبر Auth وREST لقراءة العيادات والخدمات وإضافة العيادات وتعديلها. عند انقطاع الإنترنت يرجع تلقائياً إلى قاعدة البيانات المحلية الموجودة على الهاتف.

## الدخول

- يمكن استخدام البريد الإلكتروني لحساب Supabase.
- الحسابات التجريبية القديمة `Bahnasy` و`booking_demo` مدعومة كاختصار، والأفضل استخدام البريد الإلكتروني.
- صلاحية `founder` و`booking` تسمح بإدارة العيادات والخدمات وفق سياسات Supabase.

## البناء

```bash
gradle assembleDebug
```

الناتج: `app/build/outputs/apk/debug/app-debug.apk`.
