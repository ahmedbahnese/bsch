# تطبيق Android مستقل — BSCH Clinics

يعمل التطبيق بقاعدة IndexedDB محلية داخل الهاتف، ويقدم الحجز والمتابعة والدور بدون خادم أو شبكة. شاشة المزامنة اختيارية فقط، وتستخدم عند توفر شبكة محلية مؤقتة لإرسال الحجوزات إلى Windows وسحب العيادات والحجوزات.

## البناء

```bash
gradle assembleDebug
```

الناتج: `app/build/outputs/apk/debug/app-debug.apk`.

رمز المزامنة الافتراضي: `BSCH-LOCAL-SYNC` ويمكن تغييره لاحقاً.
